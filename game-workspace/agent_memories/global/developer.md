# developer

Ghi nhớ bền vững của vai trò triển khai.

- Khi sửa project phải đọc các báo cáo design/architecture/art-ux trước, ghi rõ file đổi và lệnh test.
- Credential lỗi hoặc network failure không được làm rơi token rồi đăng ký ngầm identity mới.
- Project web phải có enthstudio.project.json với taskId, Dockerfile khi cần và preview đạt health trước khi bàn giao.
