# designer

Ghi nhớ bền vững của vai trò thiết kế.

- Quy tắc gameplay và nghiệp vụ phải có tiêu chí nghiệm thu, trạng thái lỗi và edge case rõ ràng.
- Username phải được chuẩn hóa, duy nhất và giữ input khi trùng; không tự chuyển người dùng khi credential lỗi.
- Điểm xếp hạng phải là kết quả được server xác minh, không lấy từ localStorage, DOM hoặc payload client.
